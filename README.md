# shopPilot-AI

## 📌 Project Description

shopPilot-AI is an AI-powered shopping assistant designed to help users find and explore products easily. It provides a simple and user-friendly interface for an improved online shopping experience.

## ✨ Features

- AI-powered shopping assistance
- User-friendly interface
- Product search and exploration
- Easy-to-use application
- Fast and simple interaction

## 🛠️ Technologies Used

- Python
- Streamlit
- Artificial Intelligence / Generative AI
